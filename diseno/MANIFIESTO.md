# Manifiesto de skills (20)

Instalar: Settings → Capabilities → Skills → subir cada `.skill`.

## Recomendadas (instalar primero)
impeccable, ui-ux-pro-max, design-taste-frontend, redesign-existing-projects, full-output-enforcement

## Opcionales (estilos concretos)
minimalist-ui, high-end-visual-design, industrial-brutalist-ui, gpt-taste, stitch-design-taste, design-system, ui-styling

## Con partes que no funcionan en chat
- brandkit, image-to-code, imagegen-frontend-web, imagegen-frontend-mobile: asumen generador de imágenes (Codex).
- design, brand, banner-design, slides: scripts/APIs externas (Gemini/Atlas) y solapan entre sí.
- impeccable: `live` y el launcher requieren red (descarga binario de GitHub con verificación sha256).

Todas validadas: name == carpeta, description ≤1024, zip íntegro, sin secrets (escaneo de patrones).
